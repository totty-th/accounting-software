# REA: ยอดขายตามพนักงาน (FlowAccount) — ผลสังเกต 01-11-2026

ทดลองบนบริษัททดลองของต้นแบบ · ไฟล์ Excel อ้างอิงอยู่ใน Downloads/FA Research (FA_ยอดขายตามพนักงาน_a = แบบละเอียด, _b = สรุป)

## ที่เห็นในต้นแบบ
- ตัวกรอง: ช่วงเวลา · พนักงาน · สถานะ · ปุ่มแสดงผล · มี 2 แท็บ: เอกสารขาย / เอกสารบัญชี (จัดกลุ่มตามผู้ทำรายการ)
- ตารางจัดกลุ่มตามพนักงาน: ชื่อ + จำนวนลูกค้าที่ขายได้ + มูลค่ารวมก่อนภาษี · ขยายกลุ่มเห็นเอกสาร (เลขที่/วันที่/ลูกค้า-โปรเจ็ค/มูลค่า/สถานะ)
- ใบที่ยกเลิก **แสดงจางแต่ไม่นับยอด** · กดเลขที่เปิดเอกสาร · สามจุดต่อแถว = พิมพ์/ดาวน์โหลด PDF
- หัวสรุป: ยอดก่อนภาษี / VAT / ยอดรวมทั้งสิ้น · Excel 2 แบบ (สรุป / ละเอียด) แต่ละไฟล์มีชีต SalesBySalespersonReport + Accounting Document

## การปรับใช้
| เรื่อง | ทำแล้ว |
|---|---|
| กลุ่มพนักงาน ขยาย/ยุบ + เอกสารในกลุ่ม | `components/EmployeeGroups.tsx` |
| ใบยกเลิก จาง ไม่นับ | `lib/sales-by-employee.ts` |
| แท็บเอกสารบัญชีตามผู้ทำรายการ | เดิมมีส่วน JV ตรง → จัดกลุ่มด้วย `acctDocs` |
| ตัวกรองพนักงาน/สถานะ | `app/reports/sales/page.tsx` |
| Excel สรุป/ละเอียด | `/reports/sales/export?mode=employee\|employeedetail` |
| สามจุดต่อแถว | PDF / ดาวน์โหลด |

## ยังไม่ทดสอบ / ไม่ได้ทำ (รอเจ้าของระบบ)
- รายการดรอปดาวน์พนักงานของต้นแบบ (ตอนทดลองว่าง) · ตัวกรองพนักงานใช้กับแท็บบัญชีหรือไม่
- แถวรวมใน Excel แบบละเอียดเมื่อมีหลายพนักงาน (รวมต่อกลุ่ม หรือรวมท้ายเดียว) — ตอนนี้รวมท้ายเดียว
- แบ่งหน้า (ต้นแบบ 20 รายการ/หน้า) · สถานะ "คืนเงินแล้ว" · ปุ่มพิมพ์รายงานของต้นแบบ
- ใบลดหนี้ไม่มีพนักงานของตัวเอง จึงเข้ากลุ่ม "ไม่ระบุพนักงาน" (ตรงกับฟังก์ชัน sales_by_salesperson เดิม)
