## 1. หน้ารายการ `/business/payment-slip`
- ตารางเดียว: ☐ · ชำระก่อนวันที่ · เลขที่เอกสาร (จุดสีตามสถานะ) · ผู้จ่าย (หลายราย คั่น ,) · ยอดจ่ายสุทธิ (ไอคอน ⓘ เมื่อมีหัก ณ ที่จ่าย) · สถานะ (ดรอปดาวน์) · สามจุด
- แถวยกเลิกจาง · ปุ่ม "สร้างใหม่" (ชำระหนี้/จ่ายเงินทุน · สร้างใบเตรียมจ่าย) · ไอคอนดาวน์โหลด Excel · ค้นหา · ท้ายตาราง "แสดงยอดรวมทั้งหมด"
- สามจุด: แก้ไข · พิมพ์ · แชร์ · ดาวน์โหลด · พิมพ์จ่าหน้าซอง · ลบ (ลบ = กล่อง "คุณกำลังลบข้อมูล ต้องการดำเนินการต่อหรือไม่?" ปิด/ลบข้อมูล — ลบได้ในสถานะรอดำเนินการ)

## 3. Flow สร้าง
1. สร้างใหม่ → เลือกประเภท: ผู้จ่ายรายเดียว / หลายผู้จ่าย (หลายผู้จ่ายส่งไฟล์ธนาคาร/e-WHT ได้)
2. เลือกผู้จ่าย → ตารางเอกสารค้างจ่าย (RI/EXP: เลขที่ ผู้จำหน่าย/โปรเจ็ค วันครบกำหนด จำนวนเงิน) ติ๊กหลายใบ → เพิ่มรายการเอกสาร
3. ฟอร์ม: เลขที่ PAY+วันที่+ลำดับ (แก้ได้) · ผู้จำหน่าย/ที่อยู่/เลขผู้เสียภาษี/สาขา · วันที่ · ชำระภายในวันที่ · ผู้จัดเตรียม · สกุลเงิน · ผู้ขอ · ผู้อนุมัติ · สาเหตุที่ขอ · ตารางเอกสาร (ลำดับ วันที่ เลขที่ วันครบกำหนด โปรเจ็ค ยอดรวมสุทธิ) · หมายเหตุ · โน้ตภายใน · ไฟล์แนบ · ☐ หักภาษี ณ ที่จ่าย · รวมรายการ/รวมเป็นเงิน/ยอดจ่าย · ข้อมูลชำระเงินของผู้จำหน่าย (เปิดฟอร์มผู้ติดต่อ: ธนาคาร ชื่อบัญชี เลขที่ สาขา ประเภท QR Swift)
4. บันทึกเอกสาร → "บันทึกข้อมูลสำเร็จ" · หัวเป็น "แก้ไข…" · สถานะรอดำเนินการ · ปุ่ม "เพิ่มการชำระเงิน" เปิดใช้ (ก่อนบันทึกใช้ไม่ได้) · บันทึกซ้ำโดยไม่แก้ → "ไม่สามารถบันทึกได้ เนื่องจากไม่พบการเปลี่ยนแปลงข้อมูลในเอกสาร"
5. เพิ่มการชำระเงิน: วันที่ชำระ · ช่องทาง (เงินสด/โอนเงิน/เช็ค/บัตรเครดิต/เงินสดย่อย/ช่องทางอื่นๆ) + จำนวน + เพิ่มช่องทาง · ยอดจ่ายสุทธิ · ☐ หัก ณ ที่จ่าย (อัตรา/จำนวนเงิน + สลับ "สร้างใบหัก ณ ที่จ่ายอัตโนมัติ") · ยอดขาด/เกิน + สาเหตุ (หมวดธุรกิจ/บัญชี) · หมายเหตุ
6. บันทึก → สถานะ "ชำระเงินแล้ว" ทันที · ส่วน "บันทึกการชำระเงิน" ท้ายหน้า · ประวัติเอกสาร: อัปเดตจาก RI/EXP, "บันทึกการชำระเงิน … บันทึกบัญชีที่ PV…"
- ปุ่มบนหน้า: แชร์ · พิมพ์ · ดาวน์โหลด · เพิ่มเติม (พิมพ์จ่าหน้าซอง, ประวัติเอกสาร, ตั้งค่าเอกสาร)

## 4. การปรับใช้ (migration 0060 + UI)
| เรื่อง | ทำแล้ว |
|---|---|
| รายการตารางเดียว + ค้นหา + กรองสถานะ + ยอดรวม + ⓘ หัก ณ ที่จ่าย | `/payments` |
| ดรอปดาวน์สถานะตามตารางข้างบน | `SlipStatus` (รับใบเสร็จ = `receive_payment_slip`, รีเซ็ต = `reset_payment_slip` กลับรายการจ่ายทุกเอกสารผ่าน reset_expense/reset_goods_receipt) |
| สามจุด: แก้ไข/พิมพ์/ดาวน์โหลด/แชร์/ลบ | ลบ = `delete_payment_slip` (เฉพาะไม่มีการจ่าย) + กล่องยืนยัน |
| หน้ารายละเอียด/แก้ไข | `/payments/[id]`: ผู้จัดเตรียม ผู้ขอ ผู้อนุมัติ สาเหตุ หมายเหตุ โน้ตภายใน (`update_payment_slip`), ตารางเอกสาร + รวม, บันทึกการชำระเงิน, เพิ่มการชำระเงินต่อผู้จำหน่าย |
| ตรงกัน/มีอยู่เดิม | ช่องทางจ่ายครบ 5 แบบ (เงินสด/โอน/เช็ค/บัตร/เงินสดย่อย) · หลายผู้จำหน่าย · PDF/แชร์ลิงก์ |

## 5. ยังไม่ได้ทำ / ยังไม่ทดสอบ
- **ยกเลิกใบที่จ่ายแล้ว** (ต้นแบบมีตัวเลือกในดรอปดาวน์ แต่ไม่ได้ลองผล) → ของเราบังคับรีเซ็ตก่อน (ไม่เดา)
