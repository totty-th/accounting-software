# REA: รายงานโปรเจ็ค และ สรุปสินค้าคงเหลือ (FA, 1-11-2026)

## โปรเจ็ค (เมนูแยก)
- หน้ารายการ: ชื่อโปรเจ็ค · ชื่อลูกค้า/ผู้จำหน่าย · รายได้รวม · ค่าใช้จ่ายรวม · กำไร/ขาดทุน · เมนู ⋯ (แก้ไข / ดาวน์โหลด CSV / ลบ)
- นิยาม (tooltip FA): รายได้ = วางบิล+ใบกำกับภาษี+ใบเพิ่มหนี้ − ใบลดหนี้ · ค่าใช้จ่าย = ใบรับสินค้า+ค่าใช้จ่าย ไม่รวมเงินเดือน/ค่าจ้าง
- CSV รายโปรเจ็ค (ทดสอบ 1-11-2026 ด้วย EXP202611010002 ผูก TEST-PROJECT-A ราคา 500 + VAT 7%): ⋯ → ดาวน์โหลด CSV เปิดกล่องเลือกช่วงเวลา (ค่าเริ่มต้น = วันนี้–วันนี้) → ไฟล์ `<บริษัท>_ProjectReport_dd-mm-yyyy_dd-mm-yyyy.csv` UTF-8 BOM, CRLF
  - หัว: `รายงานตามโปรเจ็ค` / `ชื่อบริษัท,…` / `เลขผู้เสียภาษี :,…` / `ชื่อโปรเจ็ค,…` / บรรทัดว่าง
  - ส่วน `เอกสารค่าใช้จ่าย`: ลำดับที่, วันที่ dd/mm/yyyy, เลขที่เอกสาร, ชื่อลูกค้า/ผู้จำหน่าย, วันครบกำหนด, ประเภทค่าใช้จ่าย, ยอดรวมสุทธิ (**ก่อน VAT** = 500.00), สถานะ (เอกสารสถานะรอดำเนินการก็นับ) + แถว `ค่าใช้จ่ายรวม`
  - ของเรา: `/reports/projects/[id]/csv?from=&to=` + ปุ่ม "ดาวน์โหลด CSV" ที่แถวโปรเจ็ค
  - ทดสอบเพิ่ม: INV202611010001 (1,000 ก่อน VAT) + RI202611010001 (300) ผูกโปรเจ็คเดียวกัน → ส่วน **`เอกสารขาย`** มาก่อน (หัวคอลัมน์เดียวกับส่วนค่าใช้จ่าย รวมคอลัมน์ `ประเภทค่าใช้จ่าย` ที่ว่าง, ท้าย `รายได้รวม`) แล้วจึง `เอกสารค่าใช้จ่าย`; ใบรับสินค้าอยู่ในส่วนค่าใช้จ่าย (ประเภทว่าง, สถานะ `รออนุมัติ`) และรวมในยอดค่าใช้จ่าย 800 (ตรงกับหน้ารายการโปรเจ็ค); ใบแจ้งหนี้สถานะ `รอดำเนินการ` นับรวม
  - ยังไม่ทดสอบ: ขายสด/ใบลดหนี้ผูกโปรเจ็ค (ของเรา: ใบลดหนี้ติดลบ ตามสูตรรายได้ของหน้ารายการ), เอกสารยกเลิกในไฟล์
- ของเราตรงอยู่แล้ว (migration 0051) · เปลี่ยนเฉพาะเมนูให้แยกหัวข้อ "โปรเจ็ค"

## สรุปสินค้าคงเหลือ (เมนูแยก)
- ตัวกรอง: ณ วันที่ + คลังสินค้า (ทั้งหมด/รายคลัง) · แสดงผลรายงาน
- Excel 2 แบบ: สรุป (ลำดับ, ชื่อ, รหัส, ราคาเฉลี่ย/หน่วย, จำนวน, หน่วยหลัก, มูลค่า, ยอดรวม) และ แบบละเอียด (ใต้สินค้าแสดงชั้นสินค้าตามใบรับสินค้า/ยอดตั้งต้น พร้อมราคาต่อหน่วยตามเอกสาร)
- ที่ทำ: `lib/inventory-report.ts` · `/reports/inventory/export?mode=summary|detail` · หน้าเว็บแสดงชั้นสินค้าใต้แต่ละสินค้า
- ข้อสังเกต (ต้องให้เจ้าของยืนยัน): ชั้นสินค้าคำนวณแบบเข้าก่อน-ออกก่อนเพื่อแสดงผลเท่านั้น ส่วนมูลค่ารวมของสินค้ายึดต้นทุนเฉลี่ยเดิม จึงอาจไม่เท่าผลรวมชั้นเมื่อมีการขายออกหลายราคา
