# REA: รายงานโปรเจ็ค และ สรุปสินค้าคงเหลือ (FA, 1-11-2026)

## โปรเจ็ค (เมนูแยก)
- หน้ารายการ: ชื่อโปรเจ็ค · ชื่อลูกค้า/ผู้จำหน่าย · รายได้รวม · ค่าใช้จ่ายรวม · กำไร/ขาดทุน · เมนู ⋯ (แก้ไข / ดาวน์โหลด CSV / ลบ)
- นิยาม (tooltip FA): รายได้ = วางบิล+ใบกำกับภาษี+ใบเพิ่มหนี้ − ใบลดหนี้ · ค่าใช้จ่าย = ใบรับสินค้า+ค่าใช้จ่าย ไม่รวมเงินเดือน/ค่าจ้าง
- CSV รายโปรเจ็ค: FA ปฏิเสธเมื่อไม่มีเอกสารในโปรเจ็ค (ไม่ได้ทดสอบรูปแบบไฟล์ → รอข้อมูลทดสอบ ไม่เดา)
- ของเราตรงอยู่แล้ว (migration 0051) · เปลี่ยนเฉพาะเมนูให้แยกหัวข้อ "โปรเจ็ค"

## สรุปสินค้าคงเหลือ (เมนูแยก)
- ตัวกรอง: ณ วันที่ + คลังสินค้า (ทั้งหมด/รายคลัง) · แสดงผลรายงาน
- Excel 2 แบบ: สรุป (ลำดับ, ชื่อ, รหัส, ราคาเฉลี่ย/หน่วย, จำนวน, หน่วยหลัก, มูลค่า, ยอดรวม) และ แบบละเอียด (ใต้สินค้าแสดงชั้นสินค้าตามใบรับสินค้า/ยอดตั้งต้น พร้อมราคาต่อหน่วยตามเอกสาร)
- ที่ทำ: `lib/inventory-report.ts` · `/reports/inventory/export?mode=summary|detail` · หน้าเว็บแสดงชั้นสินค้าใต้แต่ละสินค้า
- ข้อสังเกต (ต้องให้เจ้าของยืนยัน): ชั้นสินค้าคำนวณแบบเข้าก่อน-ออกก่อนเพื่อแสดงผลเท่านั้น ส่วนมูลค่ารวมของสินค้ายึดต้นทุนเฉลี่ยเดิม จึงอาจไม่เท่าผลรวมชั้นเมื่อมีการขายออกหลายราคา
