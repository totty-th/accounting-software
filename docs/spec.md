# สรุปสเปกเฟส 1

ฉบับเต็มอยู่ในหน้า artifact (บอร์ดแยกตามหมวด + เคสทดสอบ AT-01..AT-12)

## ตัดสินใจแล้ว
- D-01 ลงบัญชีสินค้าคงเหลือ + ต้นทุนขายจริง (เพราะมีการผลิต)
- D-02 ต้นทุน moving average
- D-03 สต็อกติดลบ: อนุญาตพร้อมคำเตือน ตั้งให้บล็อกได้ต่อสินค้า
- D-04 ยกเลิกใบเสร็จแล้วสถานะใบแจ้งหนี้ย้อนกลับ
- D-05 ลบแบบ ภ.พ.30 ให้สร้าง -R

## รอตัดสินใจ
- D-06 การผลิต: วัตถุดิบ/หน่วยนับ, BOM และเศษเหล็ก, ต้นทุนแปลงสภาพ (รอผู้บริหาร)

- M2 SAL-01..07, MST-01/02: ✅ migration 0002 + tests/m2-sales.test.ts (15 เทสต์ผ่าน)
  - ข้อที่ผมสันนิษฐานเอง (ต้นแบบไม่ได้ทดสอบ ให้ผู้ทำบัญชีทบทวน): ใบลดหนี้ห้ามเกินยอด INV ที่เหลือ; ยกเลิก INV ที่มี CN ผูกอยู่ไม่ได้; ออก DN ได้เฉพาะ INV สถานะรอเก็บเงิน
  - ยังไม่ทำ: รายการเหตุผลใบลดหนี้ตามกรมสรรพากร (ตอนนี้เป็นข้อความอิสระ), รีเซ็ต QT, การตัดสต็อกตอนบันทึก INV (M5), เมนู/สถานะที่ขึ้นกับใบเสร็จ (M3)

- M3 RCV-01..07, DEP-01..04: ✅ migration 0003 + tests/m3-receipts.test.ts (20 เทสต์ผ่าน, รวมทั้งโปรเจกต์ 48)
  - ใช้ D-04: ยกเลิกใบเสร็จแล้วสถานะ INV ย้อนกลับตามใบเสร็จที่เหลือ (รอเก็บเงิน / แบ่งจ่าย / เปิดใบเสร็จแล้ว)
  - ข้อที่สันนิษฐานเอง: WHT ของงวดแบ่งจ่ายคิดตามสัดส่วน งวดสุดท้ายรับส่วนที่เหลือ; ใบเสร็จรวมหัก CN สุทธิ และดึง DN ที่ยังไม่รับเข้ามา; ใบเสร็จเดี่ยวของ INV ที่มี CN ทำไม่ได้ (ต้องใช้ใบเสร็จรวม); ยกเลิกเอกสารที่มีใบเสร็จผูกอยู่ไม่ได้; มัดจำ 1 ใบต่อ QT; ยกเลิก INV มัดจำ/สุดท้ายแล้วสถานะ QT ย้อนกลับ
  - DEP-03 ออกแบบเอง: ใบเสร็จของ INV ฉบับสุดท้ายรับยอดสุทธิหลังหักมัดจำตามปกติ (535) และใบเสร็จของ INV มัดจำรับแยก
  - ยังไม่ทำ: ใบเสร็จรวมจากใบวางบิลโดยตรง, VAT ในใบเสร็จรับเงินอื่นๆ, ยกเลิก/รีเซ็ต QT มัดจำตามที่ต้นแบบทำ (ยังไม่ทดสอบ)
